Vim Ex commands (Vim mode only)

File

:w :write
Save current file
:e :edit
Reload current file from disk (standalone: refuses if dirty, use :e! to force)
:e!
Force reload, discarding dirty buffer
:sav :saveas
Show the save-as dialog
:new :enew
New empty buffer
:open :op
Show the file picker dialog

Preview

:syncpreview :syncp
Snap preview to the block containing the caret line

Find

:find
Open find and replace

Format

:format
Show the current format
:format name
Set format: asciidoc / markdown / text
:asciidoc :markdown :text
Direct shortcuts for each format

Syntax

:syntax :syn
Show whether editor syntax highlighting is on or off
:syntax on :syntax off
Turn editor syntax highlighting on or off (mirrors Ctrl+Alt+Y)

Spelling

:spell
Show whether spellcheck is on or off (English only)
:spell on :spell off
Turn spellcheck on or off (mirrors Ctrl+Alt+K)
:spellgood
Add the word under the cursor to your custom dictionary (Vim zg)
:spellundo
Remove the word under the cursor from your custom dictionary (Vim zug)

Width

:width
Show the current single-pane width mode
:width narrow :width medium :width wide :width full
Set the width mode explicitly (mirrors Ctrl+Alt+C's cycle)

Table of contents

:toc
Show whether the table of contents visibility override is on or off
:toc on :toc off
Show or hide the table of contents (mirrors Ctrl+Alt+I, resets on launch)
