Vim Ex commands (vim mode only)

File

:w :write
Save current file
:w filename
Write buffer contents to a path (current buffer association unchanged)
:sav :saveas filename
Save as + rename the buffer
:e :edit
Reload current file from disk
:e filename
Open a different file (refuses if dirty)
:e! :e! filename
Force reload or open, discarding dirty buffer
:new :enew
New empty buffer
:open :op
Show the file picker dialog

Quit

:q :quit
Quit (confirm if dirty)
:q! :quit!
Force quit, discard changes without prompting
:wq
Save and quit (always writes, updates mtime)
:x :exit :xit
Save only if dirty, then quit (mtime untouched on clean buffer)
:x!
Force save even if clean, then quit
:qa :qall
Quit all (single-window alias for :q)
:qa! :qall!
Force quit all
:wqa :wqall
Save all, quit all
:xa :xall
Save if dirty (all), quit all

Preview

:syncpreview :syncp
Snap preview to the block containing the caret line

Format

:format
Show the current format
:format name
Set format — asciidoc / markdown / text
:asciidoc :markdown :text
Direct shortcuts for each format

Syntax

:syntax :syn
Show whether editor syntax highlighting is on or off
:syntax on :syntax off
Turn editor syntax highlighting on or off (mirrors Ctrl+Alt+Y)
